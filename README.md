# + MATAVIEWER"
PROVIDES FREE_CAMERA FUNCTIONS FOR MATAS"

## + INSTALLATION"
1. Install [GDPatch](https://gdpatch.dev/)
2. [Download this repo as a .zip](https://github.com/elysiaisalive/cicadamata-mataviewer.git)
3. Unzip the mod into your mods folder located in (`GDPatch/mods/mataviewer`)
4. You may now view freely.

## + CONTROLS"
- `toggle_freecam - look_down_key`
- `speed_up - mousewheel_up`
- `speed_down - mousewheel_down`
- `move_camera - movement_keys`
- `move_down - stomp_key`
- `move_up - jump_key`

### Please. Enjoy the view.
